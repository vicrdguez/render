# Rationale

1. I chose inherited project defaults for general agents and exact selections for restricted roles. Exact lists everywhere would preserve today's behavior but make websearch a change to every interested role. Forced extensions would defeat the reviewer. An optional entry point distinguishes workflows without a separate type tree.

2. The six extension steps reuse binding, options, registry installation, and conversation calls. I rejected a new activation operation and automatic retries of old user requests. Missing code removes a tool, not necessarily a whole project's ability to work.

3. Lane fails core admission because W1 can build it from existing parts and no second unlike user needs it. A shared helper also lacks two creation sites and would need to own dispatch tasks. I rejected counting repeated work items as call sites. A W1-private trial tests the claimed benefit against fresh workers reading notes.

4. Ownerless workers avoid coupling their lifetime to the lane's model run. Short dispatch tasks avoid persistent waits and another supervision mechanism. Passive outcome writes preserve feedback without running the lane merely to acknowledge each result. Work still owns the evidence chain. A reset changes the current conversation ID rather than deleting or rewriting history.

5. I separated stored history, a model-written summary, and fallible notes. I rejected treating compaction as verified memory or a lane steer as a broadcast. The trial pays extra requests and can preserve wrong beliefs. Review and owner inspection remain necessary.

6. I generalized the existing host contract rather than introducing extension services. Write-only options avoid a separate credential system, but plaintext storage is a deliberate weakness. The library gets no Lane abstraction, and the core gets no workflow memory policy.

7. I chose source checks over a probe. A small faux-model run could check mechanics, but it would not establish better briefs, safe provider error handling, or codemode's behavior. Those remain explicit gaps rather than inferred successes.
