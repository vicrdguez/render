# Rationale

1. I chose a capability list over a protocol or client sketch. Most calls expose pi-durable records with device checks. Separate creation and input keep the existing transaction rule visible. I rejected a creation receipt because the owner explicitly accepted duplicates.

2. The script uses the existing walk rather than replacing W1's failure handling. Fresh input after a failed run is enough for step 6. A monitor task would add policy the ruling excludes. Changing options alone never mutates an active agent.

3. I chose stable project IDs, a small catalogue file, and project identity in each store. Client-supplied filesystem paths would contradict topology.md. Workflow additions are enough for this script. I rejected removal because draining live work or retaining disabled definitions would add another lifecycle policy. This is a version-one restriction, not a claim that removal is impossible.

4. I chose workflow-owned session documents over either JSON-file location. Dispatch can read and save the value in its own commit. The helper takes a document token so library.md's no-owned-storage rule stays intact. A helper that secretly defines a library document would violate that rule. A settings service, migration framework, and model-specific core fields are unnecessary. Full replacements are cheaper to explain than patches, but a late resend can overwrite a newer edit.

5. All faults include the tasks missing from decisions. An unreferenced-only filter would require a decision join and a precise rule for old continuation IDs. I rejected both that join and an onReport cache. Terminal task records already hold the evidence.

6. I chose ordinary submissions for owner intervention. A special workflow chat channel would duplicate queues and weaken transcript evidence. Host controls expose neither a general settings editor nor a way to skip workflow checks.

7. The new shared contract stays in the host. Option storage stays with each workflow. Generic document exposure and workflow lifecycle callbacks remain out. Each core addition still needs the owner's admission decision.

8. Source reading is enough for a paper candidate, not acceptance evidence. I did not run a probe that could be mistaken for testing the unbuilt host. The missing integration checks are stated rather than implied to have passed.
