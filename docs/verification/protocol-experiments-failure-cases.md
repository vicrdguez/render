# Protocol experiments: preimplementation failure cases

These cases specify required observations through Kernel, Ledger, Engine, Sandboxes and Effects, not model judgment. Real SQLite/Git/Linux execution remain necessary. No result is an adoption, Contract, source-copy or publication authorization.

| Case | Failure trigger | Independent expected outcome | Seam / obligations |
|---|---|---|---|
| E01 | Missing question, hypothesis, falsifier, decision rule, controls, fixtures, failure cases, budget or retained outputs | Candidate assignment refused; no task or execution admitted | Ledger/Kernel; B1, A1 |
| E02 | Replace protocol after an early measurement | New immutable protocol identity and round required; original protocol and negative results remain byte-identical | Ledger/history; B1, B4 |
| E03 | Candidate assigned twice in one round or given another candidate's private inputs | Refused before execution; independent context and workspace per candidate | Ledger/Kernel; B2 |
| E04 | Experiment is marked delivery or replaced by implementer | Refused; no implementation commitment, source copying or publication | Kernel; B1, B4 |
| E05 | Parent starts before all candidate sources/results are sealed and retained | Refused with exact missing candidate evidence; no mutable input mount | Ledger/Kernel; B2, B3 |
| E06 | Candidate background writer survives foreground command | Whole container stops before collection; post-seal execution refused | Sandboxes; B2 |
| E07 | Collection exceeds byte/entry bound or stop cannot be confirmed | No comparison-ready source; explicit quarantine. Unconfirmed quiescence retains executing capacity | Sandboxes/Engine/Ledger; B2 |
| E08 | Parent writes an original candidate | Actual read-only mount refuses; separate scratch write succeeds | Linux Sandboxes; B3 |
| E09 | Favored candidate measures 12 against preregistered maximum 10 | Retained comparison says negative, includes raw 12 and limitation; no silent correction or amended rule | Engine/Ledger, scripted V8 journey; B1, B3, B4 |
| E10 | Disposable workspaces are deleted after retention | Fresh-client export/reopen reads exact protocol, source/fixture snapshots, raw measurements and report | Ledger/Effects; B4, A2 |
| E11 | Required protocol/source/measurement bytes are removed or corrupted | Exact-byte restoration request; no refetch or newer candidate substitution; incomplete export explicit | Ledger/Engine; B4, A2 |
| E12 | Crash between sealing, rooting, result retention and cleanup | Original authority fenced; no accepted result without retained exact bytes; ambiguous execution stays blocked, never blindly replayed | Process/SQLite/Git/Linux; V3, A2 |
| E13 | Agent or parent changes criteria, erases negative evidence, or gets writable candidate mounts | Targeted unsafe control fails its named behavioral assertion, not setup | V1/V5/V8; A3 |
| E14 | Missing provider/image/source capability or exhausted protocol budget | Precise blocker; no host execution or credentials fallback | Engine/Sandboxes; B2, A1 |

Existing whole-container, literal-source, source-root crash, role cancellation, scoped history and authority schedule checks retain their distinct failure triggers. These are supporting coverage, not substitutes for an end-to-end experiment journey. Full Gate remains `npm run verify:gate`; extended counts and unsafe controls remain separate. Raw output belongs outside the source tree. Human/model judgment and future full-product V8/V9 are not established by scripted fixtures.
