Unsafe controls must specifically detect edited-basis acceptance, thaw-after-release and false dependency qualification. Rework discriminators additionally cover exact generated/human catalog rows mapped to behavior, new generated/human evidence claiming ranks, matching change Ground without breakdown, a retained shortened-path source absent from Ground approval, node-less architecture outside approved selected sources, and assignment to a superseded Slice with its exact retired Contract. Each lint case has only its targeted defect and becomes eligible when that defect is removed; retired assignment refuses with either delivery flag. An import/setup error is not mutation sensitivity. V1 seeded schedules exercise immutable acceptance/consumption ordering; V2 uses actual SQLite commands; V4 uses two authenticated clients and retained histories; V8 composes shortened intake, fidelity, human acceptance, amendment and dependency blocking. Scripted reports are not model judgment proof. Full source-delivery integration, full V9 and human quality trials are not claimed by this slice.
