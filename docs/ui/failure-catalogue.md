# Failure catalogue

> **Supporting file of the Render UI spec** ([`spec.md`](spec.md)), for the Brief design adopted on 2026-11-06.
> - **File names** in code spans: `visual-language.md`, `grammar.md` and `stack.md` are in [`reference/`](reference/); `layout.md` and `text-mocks.md` are in [`wireframes/`](wireframes/).
> - **Measured, looked-at and reasoned** claims, and what is owed, are labelled in [`evidence.md`](evidence.md).


Written before any mockup or keymap entry, per `CLAUDE.md` ("FIRST write all the ways it could fail"). Every screen in `text-mocks.md` and every rule in `grammar.md` cites the IDs it defends. A failure without a check is a design gap, not a defended case.

**Scope.** Ways the client can (M) mislead about state, (T) act on a different target than the one shown, (S) let agent content impersonate chrome, (K) trap the keyboard or muscle memory, (L) lose input, (W) mishandle the wire, (R) fail re-entry, (P) degrade under load into one of the above, or (Q) be unpleasant or misleading to read. The Q group exists because an early prototype shipped mid-word wrapping that no check caught. Server-side guarantees (spec I1–I20) are assumed; this catalogue is about the client making them visible or wasting them.

**Cases:** 220 live (M 74, T 23, S 25, K 27, L 14, W 13, R 8, P 9, Q 27). FC-Q20 and FC-Q25 are retired; see the end of the file.

**Evidence tags** mark the cases the Brief added or rewrote:
- **[measured]**: a check ran over the Brief prototype's 76 rendered states in the final run of 2026-11-06 (20:05), after the owner's changes that day and the challenge rulings. The numbers come from that run's `checks.json` (`~/dev/render-ui-design/experiments/e10-modern/proto/png/`).
- **[looked]**: a person looked at the named render, from the same final run (`mockups/`).
- **[reasoned]**: argued, not tested.
- **[owed]**: the check doesn't exist yet, or hasn't run on the Brief.

Untagged cases keep the check and evidence they had in the accepted package ([`evidence.md`](evidence.md)); the Brief didn't change them. The Brief prototype is HTML, so nothing tagged here is measured in the native client.
